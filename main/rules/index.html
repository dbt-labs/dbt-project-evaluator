List of the rules currently defined#

Each rule is a native dbt check with the name listed in the last column. Use it to run, configure or select a given rule, for example with dbt check fct_root_models. The same name is the key to use to accept some violations of a rule. The checks are tagged with their type, for example dbt ls --resource-type check --select tag:modeling.
